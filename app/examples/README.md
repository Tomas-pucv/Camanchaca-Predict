# Ejemplos de la demo

La galería de ejemplos de la demo usa las imágenes (`.jpg`, `.jpeg`, `.png`,
`.webp`) de esta carpeta. Si está vacía, la app genera en tiempo de ejecución
**2 escenas procedurales sintéticas** con niebla (`sintetico_niebla_*.jpg`), que
no son fotos reales.

## Qué se puede agregar

- **Fotos propias** del equipo, idealmente del Camino La Pólvora (Valparaíso)
  con y sin camanchaca. Anotar en el nombre fecha y hora, p. ej.
  `polvora_2026-11-03_0730_niebla.jpg`. Si se conoce la visibilidad (postes o
  señales a distancia conocida), indicarla: `..._v80m.jpg`.
- Imágenes con licencia **Creative Commons** que permita redistribución
  (CC0, CC BY, CC BY-SA), citando autor y licencia en una línea de este archivo.

Quitar los metadatos GPS del EXIF si la foto revela ubicaciones privadas, y
reducir el tamaño (lado mayor ≤ 1600 px) para no inflar el repositorio.

## Qué NO se puede agregar

**Nunca** imágenes de Cityscapes / Foggy Cityscapes, RESIDE, HazeRD u O-HAZE (ni
recortes o versiones procesadas): sus licencias prohíben redistribuirlas, y esta
carpeta se publica en GitHub (y eventualmente en un Space). Tampoco fotos con
personas o patentes identificables sin consentimiento.
